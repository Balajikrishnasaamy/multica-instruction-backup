- It needs the **FortiClient VPN connected** (`scutil --nc status VPN`). Without it ReactorWorkerService fails with `ZMLibraryServiceException: Exception while getting zookeeper information` / `ConnectException: Operation timed out` (a ZooKeeper host on port 54310; find it with `grep 54310` in the application log).
